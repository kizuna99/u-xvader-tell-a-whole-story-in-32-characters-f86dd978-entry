A tiny Python program (`main.py`) that writes one Wi-Fi network name to `/output/entry.txt` for the make.fun "Tell a Whole Story in 32 Characters" bounty: "Dad finally came back with milk" — 31 characters in which a single word, "finally", carries the whole story of the dad who went out for milk years ago and has only now returned. Run it with `python3 main.py` (set `OUTPUT_DIR` to override the output directory); the output is byte-identical on every run and inside the 1–32 character gate.
